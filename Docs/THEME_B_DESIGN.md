# Theme B：廢棄星鑄工坊 / Abandoned Astral Foundry

Phase 3 內容方向（2026-10-02）。保留 EMBER 的黑暗材質、暖金細線、青色記憶光與遠距觀察構圖；6–10F 改以工業建築與失效星象機械敘事，離開前五層根冠石環。

## 敘事與視覺

工坊曾以星光鑄造見證者的兵器，如今生產命令仍持續，卻已沒有工匠。輸送軌道、封閉觀測窗、空置工位、破裂星盤與停擺搬運臂呈現這段歷史。不是更換地面顏色：平台改為矩形工作台、縱向軌道、分割坩堝、雙層反應爐與塔心齒輪台。

黑鐵承重梁、霧面深藍金屬、磨耗黃銅、乳白陶瓷隔熱片、紫色星晶。照明分三層：冷藍漫射環境、暖橘熔爐輪廓、青色可互動導管。霧置於遠景，保留地面攻擊與角色對比；不靠昂貴後製提高品質。

地標：入廠門架、雙軌移動吊橋、三座星晶孵化器、失控加壓裝置、巨型天球鑄心。邊緣管線與空置工位位於可行走區外；中央戰鬥區遵循模擬邊界，裝飾不是隱形障礙。休息層是隔離維修間：床鋪為修復艙、教堂為記憶端口、熔爐為校準台；九種設施仍使用原規則與 ID。

VFX 語法：橘色實線/地面形狀＝傷害預警；青色環＝可打斷；紫色＝狀態與抽取；金白＝弱點命中；暗紅＝狂暴；灰藍＝無敵。形狀與顏色同時編碼，AI 讀取同一結構化 cue。預警與命中使用不同時段，避免只靠紀錄辨識。

聲音採可重用合成音效事件：低頻工廠底噪、緩慢金屬脈衝、星晶高音、警示三音、打斷短促降音、階段低沉鐘聲。環境/機械與戰鬥層分開；不是最終配樂，合成資產需後續聲音製作。
