# Agent action logic · 角色行動邏輯

Agents combine scored goals with local tactical decisions and engine-enforced safety. A selected goal is a proposal; the executed action can change when danger, legality or team needs intervene.

![Agent decision flow](../Media/Diagrams/decision-flow.png)

## 1. 觀察與候選目標

高階快照包括生命／魔力比例、剩餘時間、到出口的估計時間、材料、已知設施、人格、關係摘要與記憶來源。未發現的設施不會自動成為可互動選項；角色先選擇搜尋房間，搜尋與討論都消耗時間。

`RuleBasedReasoner` 對合法目標計算效用，選擇最高分。不同冒險傾向、好奇心、貪欲、同理心和關係，會改變探索、支援、讀遺書、製作、離隊與撤離的排序。

## Combat

在戰鬥中，執行器依序處理資源恢復、壓力核心危險、Boss 預警與地面危險。角色若在危險區，優先朝可達安全候選位置移動。安全後才處理核心目標或通常的戰術。

戰術候選包含普攻、已裝備技能、武器灌注與保護隊友。後續穩定化／協作政策可能改寫意圖：保留魔力、避免無效施法、優先搶救瀕死者、避免重複護盾與嘲諷。實際施法仍檢查武器、解鎖／裝備、魔力、冷卻與距離。

**角色定位：** 戰士以力量與攔截為主；弓箭手以敏捷與遠距輸出為主；法師以智力與法術爆發為主；補師以智慧、治療與支援為主。它們是可調整的政策與數值，不是強制演出的劇本。

### 看得見的持續傷害

原本不易理解的環境扣血改為可摧毀壓力核心：每個來源獨立冷卻、預警 3 秒、脈衝 5 秒，半徑 3。角色可移出範圍或破壞核心；核心被摧毀後不再脈衝。加速只影響下一個冷卻，不跳過預警。其他持續傷害仍有獨立來源，例如狀態、危險地面和召喚物，不能全部誤認為核心傷害。

## 2. 支援決策不是「誰血最少就補誰」

預測治療估計移動至施法範圍前的傷害、持續恢復及其他補師已準備的治療。高過量治療、較遠距離與需求已被預約的目標降低順位；瀕死情況仍可搶救，不盲目等待。

群補需至少兩名隊友有足夠需求。多補師隊可分配群補／淨化與守護／復活；多戰士隊保留主要攔截者。技能欄位維持四格，僅選已解鎖技能。這些協作檢查會對人格決策加上限制，因此不能宣稱行為完全不受設計政策引導。

## 3. 休息層的探索與撤離

路程不是直線猜測：障礙與建築共用可通行足跡，BFS 找到路徑，再平滑合法路段。選擇設施會考慮前往、工作與回到出口的時間。時間不足時有明確風險扣分，而不保證所有 Agent 一定安全離開。

未知房間可能有設施，也可能沒有。過度搜索、長時間討論、繞路與偏冒險的選擇都可能造成撤離失敗；在觀察介面可追蹤目前目標與結果。

## 4. 為什麼看起來像「學習」？

角色會保存帶來源的知識與事件，下一輪讀過遺書後可裝備應對技能，並增加已知招式的閃避餘裕。這是**記憶驅動的政策調整**。目前沒有訓練神經網路或進行 reinforcement learning，權重也不是線上學習取得。
