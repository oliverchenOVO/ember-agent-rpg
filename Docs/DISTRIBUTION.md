# Windows distribution status

The recorded local Team Balance Player was built with Unity 6000.2.0f1. This release falls below the fixed 6000.2.6f2 version in [Unity's CVE-2025-59489 advisory](https://unity.com/security/sept-2025-01). The original executable is preserved locally and will not be uploaded unchanged.

A separate portfolio copy is being remediated using the [official Unity Application Patcher](https://unity.com/security/sept-2025-01/remediation). Public binary distribution remains pending until patch integrity, notices and extracted-package checks complete. No download link is advertised as ready at this stage.

The repository preserves the complete original source history. Source publication and executable distribution have distinct evidence; publishing source does not certify the old runtime. Long simulation/soak tests are not part of this packaging task.
