# 個人網站介紹文案

## 繁體中文

**EMBER · 見證之塔｜自主 Agent 的可觀察實驗環境**

EMBER 提供可搜尋與篩選的 Agent 行為紀事及詳細挑戰紀錄，讓觀察者不只能觀看 AI 戰鬥，也能追蹤其決策、隊伍配置、存活者、輸出、治療與歷史配置。閱讀介面保留原本播放狀態，輸入焦點與模擬控制隔離。

Unity 6／C#、效用決策、有限來源記憶、有向關係、二十五層進度、製作與技能灌注。這是持續迭代的研究與作品集原型；行為變化來自規則、人格、記憶與經歷，並非已訓練的強化學習策略。

## English

**EMBER — an observable environment for autonomous Agents**

EMBER includes a searchable Agent chronicle and detailed run history, allowing observers to inspect not only combat outcomes but also decisions, team compositions, survivors, damage, healing and retained builds. Inspection preserves playback state and isolates text input from simulation controls.

Built with Unity 6 and C#, it combines utility decisions, finite source-aware memory, directed relationships, a 25-floor tower, crafting and skill infusion. Behavioral changes follow rules and accumulated experience; no trained reinforcement-learning policy is claimed.
