# 實機圖集

靜態遊戲圖片皆來自 Windows Player。部分圖片使用腳本設定的受控測試狀態，並非連續自然遊玩的錄影。歷史畫面均標示當時版本，不代表最新版再次通過那些歷史測試。

所有遊戲畫面均為實機截圖，未使用 AI 生成或修改遊戲內容。歷史版本、受控 fixture 與最新 Team Balance 畫面分開標示；範例狀態不代表自然遊玩通關。
